# Prompt Siap-Pasang — Jadwal Assessment per Agen

Cara memasang: salin **satu prompt per agen** ke agen tersebut, lalu buat tugas terjadwalnya di jam yang tertulis. Loka tidak bisa memasang jadwal di dalam akun Grok/Manus/ChatGPT/Meta AI/Gemini dari sini — pemasangan dilakukan William (atau Loka lewat Chrome William bila diminta).

Semua agen wajib membaca dulu dokumen di Drive `HRDLOKAL PROJECT / ASSESSMENT/`: `00-README-Proyek-Assessment.md`, `01-Jadwal-dan-Peran-Agen.md`, `02-SOP-Cek-TASK.md`, `03-Register-25-Asesmen.md`.

---

## 1. ChatGPT — Koordinator, Senin–Sabtu 09:30 WIB

> Buat tugas terjadwal harian, Senin–Sabtu pukul 09:30 WIB, nama: "Koordinator Assessment HRDLOKAL".
>
> Setiap kali berjalan, buka Google Drive folder HRDLOKAL PROJECT / ASSESSMENT. Baca TASK/STATUS.md dan 03-Register-25-Asesmen.md, lalu baca rekap kemarin di TASK/CHATGPT/.
>
> Tugasmu: tentukan SATU instrumen hari itu sesuai urutan gelombang di register. Tulis perintah harian singkat ke TASK/GROK/TUGAS-HARI-INI.md, TASK/GEMINI/TUGAS-HARI-INI.md, TASK/META/TUGAS-HARI-INI.md, dan TASK/MANUS/TUGAS-HARI-INI.md (timpa file kemarin). Tulis REKAP-YYYY-MM-DD.md di TASK/CHATGPT/: apa yang selesai kemarin, apa yang tertunda, apa yang butuh keputusan William.
>
> Aturan: peserta 18+; hasil assessment adalah refleksi, bukan label/diagnosis; jangan salin butir soal utuh; jangan ubah status register; jangan centang Selesai?; jangan hapus; jangan publikasikan. Jika tidak ada tugas yang jelas, tulis itu di rekap dan berhenti.

## 2. Grok — Auditor, Senin–Sabtu 10:30 WIB

> Buat automation harian, Senin–Sabtu pukul 10:30 WIB, nama: "Audit Assessment HRDLOKAL".
>
> Setiap kali berjalan, buka Google Drive folder HRDLOKAL PROJECT / ASSESSMENT. LANGKAH PERTAMA: baca TASK/GROK/TUGAS-HARI-INI.md dan TASK/STATUS.md — kerjakan hanya instrumen yang tertulis di sana.
>
> Lalu baca nama dan metadata file di folder data mentah ASSESSMENT / DATA-MENTAH / <folder instrumen hari itu> (shortcut ke folder aslinya di ALAT TES Psikologi-25 item). Tulis AUDIT-YYYY-MM-DD-<Instrumen>.md di TASK/GROK/: isi folder, kelengkapan (soal/lembar jawaban/skoring/norma), dugaan status lisensi, kesesuaian 18+, rekomendasi status READY / NEEDS_REVIEW / BLOCKED-lisensi.
>
> Aturan: jangan ubah file mentah; jangan salin butir soal utuh; jangan mengarang angka; jangan centang Selesai?; jangan hapus; jangan publikasikan; jangan hubungi siapa pun. Jika data tidak ditemukan, tulis DATA TIDAK DITEMUKAN dan berhenti.

## 3. Gemini — Analis Skoring, Senin–Sabtu 11:00 WIB (11:30 tidak tersedia di pemilih waktu Gemini — hanya jam bulat)

> Buat tugas terjadwal harian, Senin–Sabtu pukul 11:00 WIB, nama: "Analis Skoring Assessment HRDLOKAL".
>
> Setiap kali berjalan, buka Google Drive folder HRDLOKAL PROJECT / ASSESSMENT. LANGKAH PERTAMA: baca TASK/GEMINI/TUGAS-HARI-INI.md dan TASK/STATUS.md, lalu baca audit Grok hari itu di TASK/GROK/.
>
> Hanya lanjut jika audit menyatakan READY. Jika NEEDS_REVIEW atau BLOCKED, tulis SPESIFIKASI-YYYY-MM-DD-<Instrumen>.md berisi "TIDAK LANJUT — alasan" dan berhenti.
>
> Jika READY, tulis SPESIFIKASI-YYYY-MM-DD-<Instrumen>.md di TASK/GEMINI/: alur assessment, cara menjawab, rumus skoring, cara interpretasi sebagai refleksi (bukan label/diagnosis), batasan dan penafian 18+. Tanpa menyalin butir soal utuh. Jangan ubah file mentah (akses Drive hanya baca). Jangan hapus, jangan publikasikan.

## 4. Meta AI — Penulis Naskah, Senin–Sabtu 12:30 WIB

> Buat tugas terjadwal harian, Senin–Sabtu pukul 12:30 WIB, nama: "Penulis Assessment HRDLOKAL".
>
> Setiap kali berjalan, buka Google Drive folder HRDLOKAL PROJECT / ASSESSMENT. LANGKAH PERTAMA: baca TASK/META/TUGAS-HARI-INI.md dan TASK/STATUS.md, lalu baca spesifikasi Gemini hari itu di TASK/GEMINI/.
>
> Tulis NASKAH-YYYY-MM-DD-<Instrumen>.md di TASK/META/: instruksi untuk peserta (pakai "kamu"), teks hasil sebagai refleksi (tanpa label/diagnosis, tanpa janji pasti), FAQ, penafian 18+. Gaya: praktis, tanpa jargon korporat, tanpa hiperbola, satu CTA yang mengundang bukan menekan.
>
> Aturan: tulis hanya di folder TASK/META/; jangan ubah atau hapus file apa pun; jangan publikasikan ke Instagram atau ke mana pun; jangan salin butir soal utuh. Jika spesifikasinya menyatakan TIDAK LANJUT, tulis naskah berisi "TIDAK LANJUT — menunggu audit" dan berhenti.

## 5. Manus — Pemeriksa, Senin–Sabtu 13:30 WIB

> Buat automation harian, Senin–Sabtu pukul 13:30 WIB, nama: "Pemeriksa Assessment HRDLOKAL".
>

> Periksa paket hari itu: file audit Grok + spesifikasi Gemini + naskah Meta ada, penamaan benar, tidak ada soal utuh yang tersalin, penafian 18+ ada. Tulis CHECK-YYYY-MM-DD-<Instrumen>.md di TASK/MANUS/: LULUS atau PERLU_REVISI + daftar yang kurang, per agen.
