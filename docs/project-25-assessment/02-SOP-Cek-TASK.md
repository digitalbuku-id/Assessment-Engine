# SOP Cek TASK — Wajib untuk Setiap Agen

## Langkah pertama setiap kali bekerja (tanpa kecuali)

1. Buka folder TASK agenmu sendiri di Drive: `HRDLOKAL PROJECT / ASSESSMENT / TASK / <NAMAMU>/`.
2. Baca `TUGAS-HARI-INI.md` di folder itu. Itulah tugasmu hari ini. Jika file itu tidak ada atau kosong, kerjakan **satu hal ini saja**: tulis `TIDAK-ADA-TUGAS-YYYY-MM-DD.md` yang menyatakan tidak ada tugas, lalu berhenti. Jangan mengambil tugas dari folder agen lain.
3. Baca `TASK/STATUS.md` (di `ASSESSMENT/TASK/`) untuk tahu instrumen hari ini dan status register.
4. Kerjakan hanya tugasmu. Simpan output di folder TASK-mu sendiri.

## Aturan penamaan output

- `AUDIT-YYYY-MM-DD-<Instrumen>.md` (Grok)
- `SPESIFIKASI-YYYY-MM-DD-<Instrumen>.md` (Gemini)
- `NASKAH-YYYY-MM-DD-<Instrumen>.md` (Meta AI)
- `CHECK-YYYY-MM-DD-<Instrumen>.md` (Manus)
- `REKAP-YYYY-MM-DD.md` (ChatGPT)
- `TUGAS-HARI-INI.md` (ditulis ChatGPT ke folder tiap agen, ditimpa tiap hari)
- `TUGAS-<Instrumen>.md` (ditulis Manus ke `TASK/CLAUDE/` saat CHECK LULUS)

## Larangan

- Jangan menulis, mengubah, atau menghapus file di folder TASK agen lain.
- Jangan mengubah `TASK/STATUS.md` kecuali kamu ChatGPT dan hanya untuk memperbarui kolom "terakhir dikerjakan" — kolom status READY/BLOCKED hanya berubah atas keputusan William.
- Jangan menghapus file apa pun. Jangan mempublikasikan apa pun (Instagram, website, mana pun).
- Jangan menyalin butir soal, kunci jawaban, atau norma proprietary apa adanya.
- Jangan mengarang angka, metrik, atau status. Jika tidak bisa memverifikasi, tulis "belum terverifikasi".
- Jangan mencentang `Selesai?` di checklist mana pun.

## Jika ada yang tidak beres

- Data mentah tidak ditemukan / folder kosong → tulis di outputmu "DATA TIDAK DITEMUKAN" + nama folder yang dicari, lalu berhenti. Jangan mengarang isi.
- Tugas dari ChatGPT bertentangan dengan SOP ini → SOP menang; tulis pertentangannya di outputmu.
- Butuh keputusan William (misalnya lisensi) → tulis di outputmu "BUTUH KEPUTUSAN WILLIAM: ..." dan jangan lanjut ke langkah berikutnya untuk instrumen itu.

## Peran Loka (pengawas proyek)

Loka memeriksa `TASK/STATUS.md` dan output harian, memperbarui register, dan melaporkan ke William hal yang butuh keputusan. Loka tidak menggantikan jadwal agen mana pun.
